Migration - Bird Flight VR Simulator

## Overview
An immersive VR bird flight simulator where you control a bird through a city environment using VR controllers. Flap your wings to gain altitude and navigate through buildings to reach the bird's migration destination.

## How to Run the Game

### Windows:
1. Extract the archive to a folder of your choice
2. Navigate to the extracted folder
3. Double-click `Migration.exe` to launch the game

## Controls

### VR Controls (Oculus Touch):
- Flight Control: Tilt and rotate controllers to steer the bird
  - Tilt forward/backward → Pitch (up/down)
  - Tilt left/right → Roll (banking)
  - Twist left/right → Yaw (turn direction)
- Flapping: Move both controllers downward simultaneously (like flapping wings)
- Calibration: Press the A or X button to reset neutral position
- Win Condition: Fly to the end of the city (Z = 1500)

### Keyboard Controls (Debug Mode - Deprecated):
- Arrow Keys: Left/Right for wing flapping
- W/S: Pitch up/down
- A/D: Yaw left/right
- Q/E: Roll left/right

### Health System:
- Starting Health: 3 hearts
- Collision Damage: Losing health (1) from building collisions
- Death: Game over when health reaches 0
